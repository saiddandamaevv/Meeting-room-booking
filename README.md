# Frontend

Веб-приложение для бронирования переговорных комнат и офисов.

## Быстрый старт

### 1. Установка зависимостей

Перейдите в папку `frontend` и выполните:

```bash
npm install
```

### 2. Запуск приложения

```bash
npm run dev
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:5173
```

### 3. Проверка сборки

```bash
npm run build
```

### 4. Запуск тестов

```bash
npm test
```

Для автоматического повторного запуска тестов:

```bash
npm run test:watch
```

## Структура проекта

```text
src/
├── api/         — запросы к серверу
├── components/  — переиспользуемые UI-компоненты
├── hooks/       — кастомные хуки
├── pages/       — страницы приложения
├── utils/       — утилиты, включая конвертацию часовых поясов (это был ужс)
└── test/        — настройки и общие тесты
```

## Технологии

- TypeScript
- React
- React Router
- Material UI
- Day.js
- WebSocket

## Архитектурные детали

- Фильтры и состояние страниц связаны с адресной строкой.
- Выбранные параметры сохраняются в `sessionStorage`, чтобы не приходилось снова вводить их при переходе между страницами.
- При закрытии вкладки состояние сбрасывается автоматически.
- Работа с датами и временем организована через требуемый часовой пояс, а данные на сервер отправляются уже в UTC.

## API

Frontend общается с backend через прокси `/api`:

```text
http://localhost:3000
```
